# PACK.IT RUN: Хомяк на монтаже

Рабочий репозиторий игры **PACK.IT RUN: Хомяк на монтаже**.

## Концепт

**PACK.IT RUN** — горизонтальный псевдо-изометрический 2D runner про боевого хомяка-техника, который спасает мероприятия от монтажного хаоса.

Игрок управляет хомяком, бежит по трём дорожкам в глубину, собирает хлеб и проектные ресурсы, уклоняется от препятствий, проходит уровни кампании и открывает бонусный сюрреалистичный уровень.

## Формула игры

- Жанр: 2D canvas runner.
- Вид: горизонтальная псевдо-изометрия.
- Игровое поле: 3 дорожки в глубину.
- Герой: хомяк-техник.
- Помощник: шоколадный русский спаниель.
- Главная валюта: хлеб.
- Основная цель: собрать пакет ресурсов и спасти мероприятие.
- Тон: техпродакшн, семейный мем, абсурдный юмор, дедлайны, кабели, хаос.

## Кампания v1.0

1. **ДК “Почти готово”**  
   Обучающий уровень: сцена, кабели, кофры, завхоз с ключами.

2. **Свадьба в шатре**  
   Хаос праздника: дождь, гости, лужи, генератор и тамада.

3. **Большой концерт**  
   Финал кампании: фермы, LED, сабы, дым, дедлайн, босс “Саб ушёл в Protection”.

4. **Детская комната: Генеральная уборка невозможна**  
   Бонусный уровень после прохождения кампании: сюрреализм, LEGO-мины, носочный шторм, плюшевый совет директоров и Сущность Срача.

## Технический старт

На первом этапе проект делается как простая браузерная игра без тяжёлого движка и сборщика:

```text
HTML + CSS + JavaScript modules + Canvas
```

Основные данные игры должны жить в конфигах:

- уровни;
- объекты;
- боссы;
- тексты;
- магазин;
- прогрессия.

Прогресс на старте хранится в `localStorage`.
