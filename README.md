# HAMSTER CREW: Хомяк на монтаже

Рабочий репозиторий игры **HAMSTER CREW: Хомяк на монтаже**.

## Концепт

**HAMSTER CREW** — мобильный псевдо-изометрический 2D runner про боевого хомяка-техника, который спасает мероприятия от монтажного хаоса.

Игрок управляет хомяком, бежит по трём дорожкам в глубину, собирает хлеб и проектные ресурсы, уклоняется от препятствий, проходит уровни кампании и открывает бонусный сюрреалистичный уровень.

## Текущий технический контракт gameplay

- Игра делается mobile-first, но gameplay проектируется landscape-first.
- Горизонтальное расположение экрана — приоритетное и основное для игры.
- Portrait допускается как вторичный режим, но не считается основным: в нём игра может умещаться хуже.
- Desktop-режим специально не развиваем.
- Canvas занимает весь доступный размер экрана.
- В landscape игровое поле расширяется на всю ширину.
- Не возвращаем contain / 4:3 / 16:9 letterbox для gameplay.
- Фоновые полосы и дорожки продолжаются за края поля.

## Формула игры

- Жанр: 2D canvas runner.
- Вид: горизонтальная псевдо-изометрия.
- Игровое поле: 3 дорожки в глубину.
- Герой: хомяк-техник.
- Помощник: шоколадный русский спаниель.
- Главная валюта: хлеб.
- Основная цель: собрать пакет ресурсов и спасти мероприятие.
- Тон: техпродакшн, семейный мем, абсурдный юмор, дедлайны, кабели, хаос.

## Кампания v1.0

1. **ДК “Почти готово”**  
   Обучающий уровень: сцена, кабели, кофры, завхоз с ключами.

2. **Свадьба в шатре**  
   Хаос праздника: дождь, гости, лужи, генератор и тамада.

3. **Большой концерт**  
   Финал кампании: фермы, LED, сабы, дым, дедлайн, босс “Саб ушёл в Protection”.

4. **Детская комната: Генеральная уборка невозможна**  
   Бонусный уровень после прохождения кампании: сюрреализм, LEGO-мины, носочный шторм, плюшевый совет директоров и Сущность Срача.

## Future obstacles

### Ферма на полу

- ID: `truss_section`.
- Тип: `obstacle`.
- Основной уровень: **Большой концерт**.
- Не добавлять в обучающий ДК без отдельного решения.
- Занимает две соседние дорожки: `0 + 1` или `1 + 2`.
- Игрок должен уйти на единственную свободную дорожку.
- Уклонение: только смена дорожки, не прыжок и не подкат.
- Визуал: короткий диагональный кусок алюминиевой фермы, лежащий поперёк двух дорожек.
- Не делать слишком длинной, чтобы объект не перекрывал всё игровое поле.

## Технический старт

На первом этапе проект делается как простая браузерная игра без тяжёлого движка и сборщика:

```text
HTML + CSS + JavaScript modules + Canvas
```

Основные данные игры должны жить в конфигах:

- уровни;
- объекты;
- боссы;
- тексты;
- магазин;
- прогрессия.

Прогресс на старте хранится в `localStorage`.
