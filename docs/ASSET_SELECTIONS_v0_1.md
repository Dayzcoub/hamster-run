# PACK.IT RUN — Asset Selections v0.1

Дата фиксации: 2026-06-03

## 1. Назначение

Этот документ фиксирует утверждённые визуальные выборы по первому персонажу игры — главному хомяку-технику.

Использовать вместе с:

- `docs/GDD_v0_1.md`
- `docs/VISUAL_DIRECTION_v0_1.md`
- `docs/ASSET_PLAN_v0_1.md`

## 2. Утверждённое направление героя

Фиксируем героя как:

```text
подтянутый боевой хомяк-техник
компактный спортивный силуэт
не толстый, но всё ещё явно хомяк
cute but serious
жёлтая строительная каска
оранжевая сигнальная жилетка
тёмный пояс с инструментами
хлеб как фирменный символ
псевдо-изометрический 3/4 game asset
```

Ключевое ограничение:

```text
не превращать в человека в костюме хомяка
```

Нужная пропорция:

```text
компактный спортивный хомяк
пухлость допустима только как хомячья милота
без большого круглого живота
без чрезмерно человеческих длинных ног
```

## 3. Утверждённая пачка поз Pack 01

Текущая пачка поз считается подходящей для направления **Pack 01 / Hamster poses**.

### hamster_run_01

Основа: вариант 1 из последней пачки.

Описание:

```text
хомяк бежит вперёд с хлебом
динамичный stride
серьёзное выражение
хороший активный силуэт для раннера
```

Назначение:

```text
основная поза бега / базовый gameplay sprite
```

Будущее имя файла:

```text
assets/sprites/characters/hamster/hamster_run_01.png
```

### hamster_jump

Основа: вариант 2 из последней пачки.

Описание:

```text
хомяк в прыжке
тело поднято над землёй
видна тень под персонажем
хлеб остаётся фирменным элементом
энергичная и читаемая поза
```

Назначение:

```text
прыжок через препятствия
```

Будущее имя файла:

```text
assets/sprites/characters/hamster/hamster_jump.png
```

### hamster_slide

Основа: вариант 3 из последней пачки.

Описание:

```text
хомяк проскальзывает под полосатой балкой
низкая поза подката
чётко читается действие slide
```

Важно:

```text
для финального игрового ассета нужно подготовить версию без самой балки,
чтобы препятствие рендерилось отдельно и не было зашито в спрайт персонажа.
```

Назначение:

```text
подкат / уклонение под низким препятствием
```

Будущее имя файла:

```text
assets/sprites/characters/hamster/hamster_slide.png
```

## 4. Что нужно поправить при финальной подготовке файлов

Перед внесением в `assets/` подготовить финальные файлы:

```text
1. Единое кадрирование.
2. Единый визуальный масштаб персонажа.
3. Прозрачный фон.
4. Без checkerboard как реального фона.
5. Одинаковое направление света.
6. Одинаковая мягкая тень или отдельное решение: тень рендерится движком.
7. Для slide убрать встроенную балку-препятствие.
8. Проверить, чтобы у персонажа не было лишних элементов, которые будут мешать анимации.
```

## 5. Renderer notes

Для этих поз использовать единый `visualKey` prefix:

```text
hamster_run_01
hamster_jump
hamster_slide
hamster_hit
hamster_celebrate
```

В `assets/manifest.json` позже прописать anchor.

Предварительные anchors:

```json
{
  "hamster_run_01": { "anchor": { "x": 0.5, "y": 0.88 } },
  "hamster_jump": { "anchor": { "x": 0.5, "y": 0.88 } },
  "hamster_slide": { "anchor": { "x": 0.5, "y": 0.82 } },
  "hamster_hit": { "anchor": { "x": 0.5, "y": 0.88 } },
  "hamster_celebrate": { "anchor": { "x": 0.5, "y": 0.88 } }
}
```

Точные anchor-значения уточнить после реального кропа PNG.
