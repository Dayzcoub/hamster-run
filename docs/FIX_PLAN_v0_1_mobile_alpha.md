# PACK.IT RUN — Fix Plan v0.1: mobile layout, player direction, alpha cleanup

Дата: 2026-06-03

## Проблемы по первому мобильному тесту

1. В landscape на iPhone сцена визуально сплющена: мало вертикального воздуха, дорожки читаются как слишком плоские полосы.
2. Хомяк визуально бежит не в ту сторону относительно движения мира.
3. У части ассетов видны белые прогалы, белая кайма и baked shadow halo вокруг теней.
4. HUD после первого compact-pass стал лучше, но для landscape нужен отдельный режим по высоте экрана, а не только по ширине.

## План исправления

### 1. Layout

- Добавить отдельный CSS-режим для `orientation: landscape` и маленькой высоты экрана.
- Не сжимать canvas чрезмерно.
- Держать HUD компактным, но оставить игровой зоне больше высоты.
- Уменьшить footer в landscape.

### 2. Псевдо-изометрия

- Разнести lane Y-координаты сильнее на низких canvas.
- Сделать дорожки чуть глубже на wide-short экранах.
- Оставить центральные lane-линии для читаемости.

### 3. Направление игрока

- Зеркалить только player sprite в `CanvasRenderer`, не меняя исходные ассеты и меню.
- Объекты и collectibles не зеркалить.

### 4. Alpha cleanup

- Добавить runtime-cleanup в `AssetLoader`: удалить белые matte edges, soft neutral halo и baked shadows.
- Движок сам рисует тень эллипсом, поэтому baked-тени в спрайтах должны быть подавлены.

## Что не делаем в этом проходе

- Не перегенерируем полностью ассеты.
- Не меняем gameplay logic.
- Не меняем уровни и прогрессию.
- Не вводим полноценный sprite atlas.

## Проверка после фикса

- Открыть GitHub Pages на iPhone landscape.
- Проверить: HUD не режется, canvas не сплющен, хомяк смотрит в сторону бега, белые ореолы стали меньше/исчезли.
- Если останутся загрязнения альфы, следующим проходом заменить исходные PNG/WebP production-clean файлами.
