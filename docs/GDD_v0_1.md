# PACK.IT RUN: Хомяк на монтаже — GDD v0.1

Дата фиксации: 2026-06-03

## 1. Суть игры

**PACK.IT RUN: Хомяк на монтаже** — горизонтальный псевдо-изометрический 2D runner про боевого хомяка-техника, который спасает мероприятия от монтажного хаоса.

Игрок бежит по трём дорожкам в глубину, собирает хлеб и проектные ресурсы, уклоняется от препятствий, проходит кампанию из трёх основных уровней и открывает бонусный сюрреалистичный уровень.

Формула:

```text
техпродакшн + семейный мем + хомяк + спаниель + хлеб + абсурдный хаос
```

Главная идея:

> Хомяк бежит не просто за рекордом, а чтобы успеть собрать мероприятие до запуска.

## 2. Жанр и камера

- Жанр: 2D runner.
- Вид: горизонтальная псевдо-изометрия.
- Экран: landscape-first.
- Герой находится слева / центр-слева.
- Мир едет справа налево.
- Игровое поле состоит из трёх дорожек в глубину.

Дорожки:

```text
       дальняя дорожка
          ─────────────────────
      средняя дорожка
    ─────────────────────
  ближняя дорожка
─────────────────────

       🐹
```

Логически игра остаётся простой:

```text
lane: 0 / 1 / 2
x: позиция объекта по дистанции
type: obstacle / collectible / powerup / event / boss
```

Изометрия должна быть визуальным слоем, а не настоящей 3D-физикой.

## 3. Управление

### Desktop

```text
A / ←             ближе к игроку
D / →             дальше от игрока
W / ↑ / Space     прыжок
S / ↓             подкат
Esc / P           пауза
Enter             подтвердить / старт
```

### Mobile / Touch

```text
свайп вверх       прыжок
свайп вниз        подкат
свайп влево       ближняя дорожка
свайп вправо      дальняя дорожка
тап               подтвердить / старт
```

## 4. Основной игровой цикл

```text
1. Игрок выбирает уровень.
2. Видит цель уровня.
3. Стартует забег.
4. Собирает хлеб и ресурсы.
5. Уклоняется от препятствий.
6. Проходит мини-события.
7. Доходит до босс-фазы.
8. Побеждает босса.
9. Получает техсводку результата.
10. Открывает следующий уровень / награды.
```

Каждый уровень должен иметь конечную цель и финал. На старте не делаем бесконечный раннер без результата.

## 5. Ресурсы

Главная валюта:

- хлеб.

Проектные ресурсы:

- кабель;
- C2;
- болты;
- ферма;
- LED-модуль;
- PowerCON;
- изолента;
- кофе;
- настил.

Каждый уровень требует свой набор ресурсов.

Оценка прохождения зависит от собранных ресурсов и количества ошибок:

```text
100%       мероприятие спасено идеально
70–99%     мероприятие запущено с косяками
40–69%     запустили, но техдир плакал
0–39%      объект не сдан
```

## 6. Здоровье и ошибки

Не используем классическое HP. Используем смешную систему допустимых косяков.

Базово:

```text
Допустимые косяки: 3
1 столкновение = -1 допустимый косяк
0 косяков = проигрыш
```

Альтернативное отображение:

```text
Нервы команды: 3
```

Усиления могут спасать от ошибок:

- каска — один удар без урона;
- спаниель — спасение один раз за уровень;
- изолента — чинит один косяк.

## 7. Главные персонажи

### Хомяк-техник

Базовый образ:

- маленькая каска;
- монтажная жилетка;
- пояс с инструментом;
- серьёзное лицо;
- хлеб как талисман.

Характер:

- маленький, но деловой;
- вечно спасает чужой хаос;
- хлеб для него священен.

### Шоколадный русский спаниель

Роль:

- открывается после первого уровня;
- один раз за уровень спасает от столкновения;
- иногда подбирает пропущенный хлеб;
- иногда смешно усугубляет хаос;
- в бонусной детской комнате играет особую роль.

Фразы / события:

```text
Спаниель нашёл хлеб. Сомнительный, но хлеб.
Спаниель активировал режим “радость”.
Спаниель заблокировал волну хаоса собой.
```

## 8. Кампания

### Уровень 1 — ДК “Почти готово”

Назначение: обучение и знакомство.

Визуал:

- районный ДК;
- сцена;
- кулисы;
- старые прожекторы;
- кофры;
- кабели;
- стойки;
- табличка “До запуска 10 минут”.

Цель:

```text
Собрать базовый комплект сцены.
```

Ресурсы:

- настилы;
- кабель;
- болты;
- C2;
- хлеб.

Препятствия:

- кофр;
- кабельная петля;
- микрофонная стойка;
- коробка с непонятными проводами;
- тележка.

Особые события:

```text
Ключи от щитовой у завхоза.
Один кабель остался лишним.
Кто забрал изоленту?
```

Босс:

#### Завхоз с ключами

Механика:

- закрывает одну дорожку;
- кидает связки ключей как препятствие;
- выкатывает тележку;
- игрок должен собрать ключи / пропуска и добежать до выхода.

Финальная фраза:

> Сцена собрана. Завхоз недоволен, но мероприятие запущено.

### Уровень 2 — Свадьба в шатре

Назначение: добавить хаос, погодные эффекты и комедийные события.

Визуал:

- шатёр;
- гирлянды;
- мокрый пол;
- столы;
- гости;
- генератор;
- кабели;
- торт на опасной дистанции.

Цель:

```text
Запустить праздник и не дать генератору умереть.
```

Ресурсы:

- кабель;
- PowerCON;
- изолента;
- LED-модуль;
- кофе;
- хлеб.

Препятствия:

- лужа;
- гость;
- стул;
- стол;
- гирлянда;
- генераторный провод;
- торт.

Особые события:

```text
Тамада просит микрофон без провода.
Гость наступил на кабель.
Невеста спросила, почему экран не по центру.
Генератор кашлянул.
```

Босс:

#### Генератор не завёлся

Механика:

- экран темнеет;
- препятствия подсвечиваются вспышками;
- нужно собрать канистру, изоленту, PowerCON и кофе;
- после сбора генератор оживает.

Финальная фраза:

> Генератор завёлся. Никто не понял как, но праздник спасён.

Назначение: финал основной кампании.

Визуал:

- большая сцена;
- фермы;
- LED;
- сабы;
- дым;
- прожекторы;
- backstage;
- дедлайн;
- кофры;
- грузчики на фоне.

Цель:

```text
Собрать полный пакет проекта до открытия дверей.
```

Ресурсы:

- фермы;
- C2;
- LED-модули;
- кабели;
- PowerCON;
- кофе;
- хлеб.

Препятствия:

- падающая ферма;
- кофр;
- дымовая зона;
- сабовая волна;
- LED-модуль на тележке;
- кабельный клубок.

Фазы:

```text
Фаза 1: Разгрузка
Фаза 2: Монтаж
Фаза 3: Запуск
```

Босс:

#### Саб ушёл в Protection

Механика:

- огромный саб мигает красным “PROTECT”;
- идут басовые волны;
- игрок прыгает / подкатывается;
- нужно собрать “перезагрузка”, “питание”, “терпение техника”;
- финальное действие — нажать большую кнопку Reset.

Финальная фраза:

> Саб перезапущен. Все сделали вид, что так и было.

После прохождения открывается бонусный уровень.

## 9. Бонусный уровень

### Детская комната: Генеральная уборка невозможна

Открывается после прохождения первых трёх уровней.

Сообщение открытия:

> Открыт секретный объект: Детская комната.  
> ТЗ отсутствует. Ответственный неизвестен. Хаос подтверждён.

Кнопка:

```text
Войти в зону срача
```

Сеттинг:

Детская комната как монтажная площадка после апокалипсиса:

```text
носки как такелаж
кубики как сцена
карандаши как фермы
LEGO как минное поле
плед как занавес
зарядки как кабели
игрушки как комиссия по приёмке
хлебные крошки как валюта
```

Главный враг:

#### Сущность Срача

Выглядит как живая куча из:

- носков;
- фантиков;
- кубиков;
- LEGO;
- карандашей;
- зарядок;
- мягких игрушек;
- хлебных крошек;
- случайного XLR;
- одной непонятной детали.

Фразы:

```text
Это не мусор, это проект!
Не убирай, я так играю!
Где вторая деталь от этого?
Пап, смотри, я построил портал!
Я только на пять минут!
```

Механики бонуса:

- дорожки иногда плывут;
- ковёр сдвигается;
- плед закрывает обзор;
- LEGO наносит критический мем-урон;
- игрушки внезапно блокируют дорожки;
- спаниель может и помочь, и устроить хаос.

LEGO-мины:

```text
Критический урон пятке. Даже у хомяка.
```

Плюшевый совет директоров:

```text
Мягкие игрушки сидят поперёк дороги как комиссия по приёмке объекта.
```

Носочный шторм:

```text
Сверху падают носки, часть из них липкие.
```

Босс:

#### Сущность Срача: Генеральная уборка

Фазы:

```text
1. Носочный шторм
2. LEGO-поле
3. Плюшевый совет директоров
4. Финальный хлеб
```

Финал:

> Сущность Срача временно отступила.  
> Следующая уборка через 17 минут.

Результат:

```text
Порядок восстановлен на 37%. Это рекорд.
```

## 12. Экран результата

После уровня показывается не просто score, а смешная техсводка.

Пример:

```text
ДК “Почти готово”

Сцена: 100%
Кабели: 83%
Болты: 95%
Хлеб: 147
Косяки: 2
Нервы команды: -14

Вердикт:
Мероприятие запущено. Один кабель остался лишним, но это нормально.
```

Оценки:

```text
S — идеально
A — хорошо
B — запустили с косяками
C — техдир плакал
D — объект не сдан
```

## 21. Арт-стиль

Направление:

```text
мультяшная техно-изометрия
```

Не пиксель-арт.  
Не реализм.  
Не совсем детская картинка.

Стиль:

- тёмный графитовый фон;
- яркие сценические акценты;
- мягкие тени;
- читаемые объекты;
- хомяк и спаниель крупные и выразительные;
- интерфейс как техсводка;
- юмор через подписи.

Палитры уровней:

- донат;

## 24. Первый кодовый коммит после GDD

Когда начнётся код, первый правильный коммит должен дать рабочий каркас:

```text
index.html
src/main.js
src/styles.css
src/data/levels.js
src/data/objects.js
src/core/Storage.js
src/core/Input.js
src/core/Game.js
src/render/CanvasRenderer.js
```

Минимальный результат первого кода:

- главное меню;
- выбор уровня;
- запуск ДК;
- хомяк на 3 дорожках;
- движущиеся объекты;
- сбор хлеба;
- столкновения;
- результат;
- сохранение прогресса.
